## Sobre o Projeto WorkServiceHub

Este projeto foi feito para o trabalho integrador do curso de Informática do *IFMG Campus Formiga* por **Hektor L**.

É basicamente um fórum com foco em tópicos sobre trabalho, incluindo divulgação de currículos, vagas e serviços.

Seu público alvo vem de usuários comuns, trabalhadores e até empresas que desejam um lugar para compartilhar seus desejos e ofertas no mercado de trabalho.
